# The sensitivity scan surface: the declared COMPLEMENT of the personal-data surface.
#
# Under goal "Sensitivity sweep" (spec: temper-artifacts specs/2026-09-28-sensitivity-sweep-design.md,
# D3 and Q9). Sibling of scripts/personal-data-surface.txt.
#
# WHY THIS FILE EXISTS.
#
# personal-data-surface.txt is built from STRUCTURE: foreign keys, polymorphic pairs, principal
# tables, vector/jsonb/bytea types, and a name heuristic. Every `text` / `character varying` column
# those derivations do not nominate used to be a stated silence in that file's header. The silence
# included the whole authored corpus (kb_block_content.content, kb_chunk_content.content), because
# `text` is the type of everything and structure cannot tell prose from a hash.
#
# This file turns that silence into a checked invariant. Every text/varchar column of a public base
# table appears in EXACTLY ONE of the two manifests:
#
#   * nominated by a personal-data derivation  -> declared in personal-data-surface.txt
#   * nominated by nothing                     -> declared here
#
# sensitivity_scan_surface_test.rs asserts the partition: the union is total, the intersection is
# empty, and a line here naming a column that is not a live text/varchar column fails.
#
# METHOD. The column set is every column of information_schema.columns with data_type in
# ('text','character varying') whose table is a BASE TABLE in schema `public`, as migrated by
# temper_services::MIGRATOR (so `_sqlx_migrations` is included). The complement is that set minus
# every `table.column` declared in personal-data-surface.txt.
#
# COUNT at 44d3a4f: 166 text/varchar columns; 18 declared in the sibling; 148 declared here.
# (The spec measured 147 at 7c6d0f2. The schema did not change between the two commits; the
# difference is `_sqlx_migrations.description`, which exists in every migrated test database.)
#
# THERE IS NO `unadjudicated` CLASS. A class that means "we will decide later" is how a manifest
# starts accumulating lines nobody reads. A new column is declared by the PR that adds it.
#
# FORMAT (line-oriented; `#` comments and blank lines ignored)
#   <table>.<column> | <disposition> | <note>
#
# disposition
#   scan          authored or user-supplied free text; the sweep reads it
#   structural    hash, enum, discriminator, surrogate, vocabulary, or a value derived from one
#   credential    secret material by design (hashed, or a short-lived plaintext bearer value); not
#                 a PII surface, and a sweep must never echo it
#   out-of-scope  anything else, with the reason in the note (a note is REQUIRED for this class)
#
# Remediability is not a column here. It comes from the sibling's `ceiling` for the surfaces the
# sweep reads through that file, and from the erasure act for the surfaces declared `scan` here.
